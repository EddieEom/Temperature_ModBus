# 실장비 시험 기록

2026년 11월 12일 시험에서 같은 알람 번호를 기준으로 WinForms 표시, SQL Server 이력, 카카오 메시지를 대조했습니다.

| 관찰한 단계 | 기록 | 확인한 동작 |
| --- | --- | --- |
| 연결 후 첫 온도 | 25.0℃ | 연결된 장비에서 응답을 받아 실제 온도로 표시 |
| 고온 판정 진행 | 90.0℃, 2/3 | 연속 샘플 수가 화면에 표시됨 |
| 알람 발생 | 19번, 93.6℃, 16:07:35 | 발생 시점의 온도와 시각을 저장 |
| 작업자 확인 | 19번, 16:08:00 | 확인 시각만 기록 |
| 정상 복귀 | 19번, 16:08:19 | 동일 이력에 별도 복귀 시각 기록 |
| 메시지·이력 대조 | 카카오 메시지, 발송 성공 표시 | 이력 화면에서 발생 온도와 세 시각 확인 |

확인 버튼을 누른 뒤 실제 복귀까지 19초가 걸렸습니다. 두 시각을 따로 기록한 덕분에 작업자가 알람을 본 뒤에도 고온 상태가 이어진 구간을 확인할 수 있었습니다.

## 코드로 확인한 예외 처리와 후속 시험

| 시험 항목 | 현재 코드에서 예상되는 동작 | 실장비 재시험 시 남길 증거 |
| --- | --- | --- |
| 센서 오류 응답 | 온도 공백, 연속 횟수 초기화, SENSOR_ERROR 기록 | 상태 코드와 DB 발생·복귀 시각 |
| 수집 중 네트워크 단절 | 수신 실패 또는 시간 초과 후 COMM_LOST 기록 | 단절 시각, 화면 상태, 재연결 뒤 첫 응답 |
| 고온 상태에서 앱 재시작 | DB의 미복귀 상태를 불러와 복귀 판정 재개 | 재시작 전후 같은 AlarmId |
| 발송 도중 중단 | 시도 횟수가 증가한 대기 건이 남을 수 있음 | 실제 메시지 도착 여부와 DB 상태 |
| DB 접속 중단 | 저장 실패 표시, 다음 유효 샘플에서 현재 상태 저장 재시도 | 장애 중 상태 전환과 복구 뒤 행 비교 |

위 예외 항목은 코드 검토를 바탕으로 작성했습니다. 문서 작성 시점에는 실장비 재시험을 수행하지 않았습니다.
